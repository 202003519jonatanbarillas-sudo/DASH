PORTAFORLIO DE DASHBOARDS

DASHBOARD DE DATOS MACROECONÓMICOS

Este dashboard de datos macroeconómicos presenta indicadores clave del sector monetario, como la base monetaria y el crédito bancario total. Incluye métricas de último valor, promedio histórico, máximos y mínimos, además de gráficas interactivas que permiten analizar tendencias de largo plazo y patrones estacionales. Su objetivo es ofrecer una visualización clara y dinámica para apoyar el análisis económico y la toma de decisiones.

DASHBOARD DE VENTAS

Este dashboard de ventas ofrece una visión integral del desempeño comercial, mostrando métricas clave como ventas totales, número de órdenes, promedio de ventas y porcentaje de devoluciones. Los gráficos permiten analizar la distribución regional, el tipo de cliente y los métodos de pago, además de seguir la serie histórica de ventas. Su objetivo es facilitar el diagnóstico de la actividad comercial y apoyar la toma de decisiones estratégicas.
