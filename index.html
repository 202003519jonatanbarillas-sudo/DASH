PROCESO ANALÍTICO

Cómo fueron construidos estos dashboards

Cada proyecto fue desarrollado siguiendo un proceso completo de análisis de datos que abarca desde la obtención y limpieza de información hasta la construcción de visualizaciones interactivas orientadas a la toma de decisiones.

01

Obtención de Datos

Utilización de bases de datos públicas, repositorios académicos y conjuntos de datos especializados para cada dominio analítico.

02

Procesamiento

Limpieza, transformación y validación mediante Python, SQL y herramientas de análisis estadístico.

03

Modelado

Construcción de indicadores, métricas de negocio, variables derivadas y modelos analíticos.

04

Visualización

Desarrollo de dashboards interactivos utilizando HTML, CSS, JavaScript y bibliotecas de visualización.

Proyecto Destacado

Dashboard de la Encuesta Nacional de Inclusión Financiera (ENIF)

Plataforma analítica desarrollada para explorar los principales indicadores de inclusión financiera en Guatemala. El sistema integra múltiples módulos temáticos, filtros dinámicos y visualizaciones interactivas orientadas al análisis económico, social y territorial de la población.

Módulos Analíticos 20+
Variables Procesadas 500+
Visualizaciones 40+
Tecnologías Python + JS
Este dashboard fue desarrollado a partir de los microdatos de la Encuesta Nacional de Inclusión Financiera (ENIF). El proyecto involucró procesos de limpieza, transformación y modelado de datos, construcción de indicadores estadísticos y desarrollo de visualizaciones interactivas orientadas al análisis económico y social de la población guatemalteca.
