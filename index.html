01

Obtención de Datos

Utilización de bases de datos públicas, repositorios académicos y conjuntos de datos obtenidos en Kaggle especializados para cada dominio analítico.

02

Procesamiento

Limpieza, transformación y validación mediante Python, SQL y herramientas de análisis estadístico.

03

Modelado

Construcción de indicadores, métricas de negocio, variables derivadas y modelos analíticos.

04

Visualización

Desarrollo de dashboards interactivos utilizando HTML, CSS, JavaScript y bibliotecas de visualización.

FLUJO DE TRABAJO

Mi proceso analítico

Cada caso de estudio se desarrolla mediante un enfoque estructurado, pasando desde la extracción y preparación de los datos hasta la construcción de visualizaciones y el planteamiento de recomendaciones de negocio.

01

Gestión de Base de Datos

Diseño, importación y manipulación inicial de las bases de datos mediante consultas estructuradas en MySQL para garantizar su integridad.

02

Limpieza y Transformación

Tratamiento, validación y preparación de los conjuntos de datos utilizando scripts en SQL y la librería Pandas en Python.

03

Análisis Exploratorio (EDA)

Análisis descriptivo y cálculo de agregaciones estadísticas para identificar patrones temporales, demográficos y financieros.

04

Visualización y Conclusiones

Desarrollo de gráficos interactivos con herramientas como Bokeh para responder a las preguntas de negocio y sugerir acciones comerciales.

Problema

⚑

Resumen del Proyecto

Objetivo

Problema

Comprender la evolución de los principales indicadores monetarios y financieros para apoyar el análisis macroeconómico y la estabilidad financiera del país.

⚑

Objetivo

Analizar tendencias, relaciones entre variables monetarias y el crecimiento económico mediante técnicas de análisis exploratorio de datos.

☰

Preguntas Respondidas

  • Evolución de agregados monetarios.
  • Crédito vs PIB.

✦

Principales Hallazgos

  • Las remesas registraron el mayor crecimiento acumulado.
  • El numerario fue el segundo indicador con mayor crecimiento.
  • El PIB mostró una recuperación posterior al COVID-19.
  • El spread en moneda nacional fue más estable que en moneda extranjera.
  • Las variables monetarias presentaron relaciones positivas con el PIB.
